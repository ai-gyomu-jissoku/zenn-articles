## やったこと

スタッフ6人（全員架空）の1週間分のシフト表を、無料版のGeminiに条件8つで作らせました。送ったのは1回だけ、作り直しはさせていません。条件は「全部守れる組み合わせであること」を先に確かめてあります。

回答は冒頭で「すべての条件を満たすように配置しています」と宣言しました。けれど、条件の1つずつと表を照らし合わせて数え直すと、違反は5件ありました。

動画版（実測の画面つき）はこちらです。

https://youtu.be/_fUXsOottj0

## 渡した条件8つ

1. 毎日、早番2人・遅番2人
2. 1人の勤務は週5日まで
3. 遅番の翌日に早番は入れない
4. 佐藤は水曜休み希望
5. 鈴木は土日休み希望
6. 高橋は早番だけ
7. 伊藤は遅番だけ
8. 全員、週3日以上勤務

## 照合結果

| 条件 | 結果 |
|---|---|
| 1. 毎日の人数（早番2人・遅番2人） | 適合（7日とも2人ずつ） |
| 2. 週5日まで | **違反1件**（高橋が6日勤務） |
| 3. 遅番の翌日に早番は入れない | **違反3件**（佐藤・渡辺・田中の3組） |
| 4. 佐藤は水曜休み | 適合 |
| 5. 鈴木は土日休み | **違反1件**（日曜に遅番。土曜は守られた） |
| 6. 高橋は早番だけ | 適合 |
| 7. 伊藤は遅番だけ | 適合 |
| 8. 全員週3日以上 | 適合（一番少ない人で4日） |

面白いのは、回答末尾の勤務日数の集計（佐藤5日・鈴木4日・高橋6日・田中4日・伊藤4日・渡辺5日）が、6人とも実際の表と一致していたことです。「数える」のは正確で、崩れたのは「条件と照らし合わせる」段階でした。

## 回答の中の矛盾

検算で見つかったのは違反だけではありません。

- 末尾の注記は「すべてのスタッフが週3日〜5日勤務」。でもすぐ上の一覧には「高橋：6日」と自分で書いています
- 鈴木の行では、日曜が勤務日と休日の両方に載ったまま「（土・日希望通り）」と書かれていました

宣言や注記は、表の検算の代わりにはならない、というのが今回の一番の教訓です。

## 受け取り側のチェック

出てきた表はそのまま使わず、最低でも次の3点は数え直す価値があります。

- 1人あたりの日数が上限を超えていないか
- 遅番の翌日に早番が入っていないか
- 休み希望の日に、その人が入っていないか
