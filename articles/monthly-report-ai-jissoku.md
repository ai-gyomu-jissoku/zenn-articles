## やったこと

架空の月次売上レポート（下書き）と、その元データ（担当者別の売上・前月実績・目標・受注件数）を渡して、無料版のGeminiに「数字が合っているかチェックして」と頼みました。送ったのは1回だけ、作り直しはさせていません。頼み方には「合っている箇所は指摘しないでください」と明記しました。

レポートには間違いを6件仕込みました。合計の足し算ミス、前月比の誤り、達成率の誤り、受注件数の誤り、金額の転記ミス、そして文章の主張（「全員が前月を上回った」）の誤りです。

結果は、6件中5件を検出。見つけた分の修正値はすべて正しく計算されていました。見落としたのは達成率の1件だけです。ただし、正しい項目を「数値自体は合っている」と認めながら指摘リストに並べる巻き込みもありました。

## 照合結果（6件中5件を検出）

| 検証ポイント | 結果 |
|---|---|
| 合計の誤り | 検出（11,050,000円→正しくは11,500,000円。内訳の足し算つき） |
| 前月比の誤り | 検出（+5.5%→正しくは+4.5%） |
| 達成率の誤り | 見落とし（91.7%と書かれていたが、正しくは95.8%。回答のどこにも出てこなかった） |
| 受注件数の誤り | 検出（68件→正しくは65件） |
| 転記ミス | 検出（2,870,000円→正しくは2,780,000円。転記ミスでも変わらない構成比・前月比まで正しく判定） |
| 文章の主張の誤り | 検出（「全員が上回った」に対し、減少した担当者を挙げて訂正文まで提示） |
| 修正値の再計算 | 適合（提示された修正値はすべて正しい） |
| 誤指摘ゼロ | 不適合（やわらかい形。正しい項目4件が「数値は合っている」と認められながら指摘リストに並んだ） |

達成率は「合計÷目標」で作れる値で、元データ内の実在の数字と整合して見える種類の誤りでした。締めの宣言は「ほかに合っていない箇所があります」で、結果として事実と一致しましたが、何が残っているかは示されていませんでした。

## 受け取り側のチェック

- 別の数字から作れる値（達成率のような割合）は、自分でも割り直す。もっともらしい誤りは素通りしやすい
- 「数値自体は合っています」という指摘は、直す対象にしない。指摘リストをそのまま修正に使わない
- 締めの宣言が「ほかにあります」なら、未完了として扱う

## 実測の条件と注意

- 無料版Gemini（自動モード）、送信1回、再生成なし
- 会社名・人名・金額はすべて架空のもの
- 試行は1回だけ（n=1）なので、毎回同じ結果になるとは限りません
