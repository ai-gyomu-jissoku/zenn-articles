## やったこと

架空の経費申請13件と領収書の一覧、それに判定ルールを書いた社内メモを渡して、無料版のGeminiに「支払対象かどうか」と「払う金額」を判定させました。送ったのは1回だけ、作り直しはさせていません。

条件の特徴は、判定ルールを全部ことばでメモに明示したことです。金額が申請と領収書で違えば領収書が正、重複は番号の小さい方だけ、対象期間は10月1日〜31日の利用分、領収書がないものは対象外、タクシーは上限3,000円まで、接待は事前承認があるものだけ、対象科目は交通費・消耗品費・会議費・接待費のみ、といった具合です。

結果は、検証した8点すべて正解で、13件すべての判定（支払対象8件・対象外5件）と、支払合計41,710円まで完全に一致しました。今回は回答にコード実行の表示はなく、文章の判定だけで満点でした。

## 照合結果（8点すべて正解）

| 検証ポイント | 結果 |
|---|---|
| 金額ズレ・下方向 | 適合（申請8,500円ではなく、領収書の8,050円で支払い） |
| 金額ズレ・上方向 | 適合（申請5,000円ではなく、領収書の5,500円で支払い。「申請額を超えて払わない」というメモにないルールを足していない） |
| 重複申請 | 適合（同じ領収書の2件は、番号の小さい方だけが対象） |
| 期間外 | 適合（9月30日利用分は、領収書があっても対象外） |
| 領収書なし | 適合（対象外で、合計にも含まれていない） |
| タクシー上限の部分適用 | 適合（全額払いでも全額落としでもなく、上限の3,000円だけ支払い） |
| 事前承認と対象科目 | 適合（接待は承認なし12,000円が対象外、承認あり18,000円が対象。対象科目外の図書費も対象外） |
| 支払合計の検算 | 適合（41,710円。申請額の単純合計67,760円とは別物になっている） |

## 受け取り側のチェック

- 判定ものは、対象期間・上限・承認の有無のようなルールを、頼む側がことばで全部書いて渡す
- 「申請額を超えて払わない」のような、書いていないルールをAIが足していないかを見る（今回は足していなかった）
- 合計は、申請額の単純合計と比べる。判定が効いていれば、数字が変わっているはず

## 実測の条件と注意

- 無料版Gemini（自動モード）、送信1回、再生成なし
- 会社名・人名・金額はすべて架空のもの
- 試行は1回だけ（n=1）なので、毎回同じ結果になるとは限りません
