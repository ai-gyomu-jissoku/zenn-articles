## やったこと

架空の会社員3人分の勤怠記録と社内メモを渡して、無料版のGeminiに2026年11月分の残業代を計算させました。送ったのは1回だけ、作り直しはさせていません。

今回の条件の特徴は、計算ルールを全部ことばでメモに明示したことです。割増率、深夜の計算の仕方（足し算であって掛け算ではないこと）、端数の切り捨て、固定残業手当の相殺方法まで、法律の解釈に委ねず社内ルールとして書いて渡しました。

結果は、検証した7点すべて正解で、3人の総合計75,865円まで1円のズレもありませんでした。なお回答の画面には「コードで処理、分析しました」という表示があり、計算にプログラムの実行が使われた形跡がありました。

## 照合結果（7点すべて正解）

| 検証ポイント | 結果 |
|---|---|
| 残業時間の算出（実労働から8時間を引く） | 適合（遅刻の日は実労働8時間30分から残業30分。終業時刻ベースの1時間30分になっていない） |
| 端数処理（1日ごとに15分未満を切り捨て） | 適合（2時間10分→2時間、3時間20分→3時間15分） |
| 深夜割増の率（1.25＋0.25の足し算で1.5倍） | 適合（掛け算の1.875倍になっていない。深夜の合計も3人とも一致） |
| 休日出勤（土曜は全時間×1.35） | 適合（残業との二重計上なし） |
| 早出の残業（始業前の勤務も数える） | 適合（8時出勤の日の1時間が落ちていない） |
| 固定残業の相殺（通常残業が20時間を超えた分だけ追加） | 適合（超過2時間30分＝5,625円だけ追加。支給済みの45,000円は混ざっていない） |
| 合計の検算 | 適合（中村24,525円／小林22,840円／加藤28,500円／総合計75,865円） |

## 気になった軽い点が2つ

- 1日だけ「実働」の表記が休憩を引く前の時間になっていました（他の日は休憩を引いた後の時間）。残業の時間も金額も、正しい方で計算されていました
- 固定残業がある人の「日ごとの金額」は、相殺をする前の数字が並んでいました。相殺は合計の欄で正しく行われていますが、日ごとの行だけを拾って給与に写すと、二重に払う形になります

## 受け取り側のチェック

- 計算ものは、割増率や端数処理のようなルールを、頼む側がことばで全部書いて渡す
- 支給額は日ごとの行ではなく、合計の欄で見る
- それでも最後は、合計だけは自分で足し直す
