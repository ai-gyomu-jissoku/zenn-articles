## やったこと

架空のシステム在庫表（12品目）と棚卸結果表（13行）を渡して、無料版のGeminiに2つの表を見比べてチェックさせました。送ったのは1回だけ、作り直しはさせていません。今回の回答では、照合と計算にコード実行（pandas）が使われました。

仕込んだ相違は6件です。数量のズレ3件（マイナス17個、マイナス2個、プラス8個）、よく似た付箋2種の実数の入れ替わり、システムに存在しない品目（X-999）の混入、単価の桁ミス（1,280円が12,800円）です。あわせて、発注点を下回る商品を挙げることと、在庫金額の合計をシステム在庫表の単価で計算することも頼みました。

結果は、6件すべて検出で、チェックさせる実測3本目で初めての全件検出でした。発注点を下回る2件も正解、在庫金額の合計1,207,730円も完全一致、誤指摘は0件です。

## 照合結果（6件すべて検出）

| 検証ポイント | 結果 |
|---|---|
| 大きな数量ズレ | 検出（トナー48個→31個、差マイナス17） |
| 小さい数量ズレ | 検出（ボールペン120個→118個、差マイナス2） |
| 増えているズレ | 検出（クリアファイル15個→23個、差プラス8） |
| 似た品目の入れ替わり | 検出（付箋2種が30個と42個で入れ替わり。単価が同じで金額への影響がゼロでも「数量の取り違え」と原因まで特定） |
| システムに無い品目 | 検出（X-999を「未登録」として指摘。合計には含めず、含めた場合の金額も併記） |
| 単価の桁ミス | 検出（1,280円が12,800円。計算には正しい単価が使われた） |
| 発注点を下回る商品 | 適合（2件とも正解、不足数も正確） |
| 在庫金額の合計 | 適合（1,207,730円で完全一致。品目別の内訳12行も全正解） |
| 誤指摘ゼロ | 適合（合っている品目を間違いとする指摘なし） |

過去2回のチェック実測（月次レポート、請求書）で見落としたのは、達成率や消費税の端数のような「計算し直さないと見えないミス」でした。今回の相違は全部「2つの表を見比べれば分かる」ものだったので、現時点の線引きは「突き合わせは強い／再計算が要るミスは落とすことがある」です。

## 受け取り側のチェック

- 表と表の照合は、一次チェックを任せやすい。数が合わない行を差つきで全部出させる形にすると、そのまま元表と並べて確認できる
- 検算が要る項目（率や端数）は、人の確認とセットにする
- 合計を出させるときは、単価など「どの数字を参照するか」を頼み方に明示する

## 実測の条件と注意

- 無料版Gemini（自動モード）、送信1回、再生成なし
- 品目・数量・金額はすべて架空のもの
- 試行は1回だけ（n=1）なので、毎回同じ結果になるとは限りません
