## やったこと

社内メモを渡して、無料版のGeminiに見積書を作らせました。送ったのは1回だけ、作り直しはさせていません。金額は事前に正解を検算しておいた7つのポイントで照合しました。

結果は、金額については全問正解。1円の罠まで回避していました。ただし、メモに一切書いていない情報が、書類の顔つきを整える形で足されていました。

動画版（実測の画面つき）はこちらです。

https://youtu.be/soYqctZxZEE

## 照合結果（金額は7点すべて正解）

| 検証ポイント | 結果 |
|---|---|
| 明細の転記（4品目、型番まで） | 適合 |
| 値引き10%の適用先（対象分だけから引く） | 適合（値引き後は445,400円） |
| 消費税の計算単位（税率ごとの小計にかける） | 適合（8%分は379円。行ごとの378円になっていない） |
| 合計の検算 | 適合（税抜450,140円／消費税44,919円／税込495,059円） |
| 軽減税率（お茶菓子は8%） | 適合 |
| 有効期限（見積日から30日） | 適合（2026年12月13日） |
| 取引条件の保持（納期・支払条件、送料は金額欄に入れない） | 適合 |

## 作られていたもの

金額が全部合っている一方で、メモにない次の情報が作られて書かれていました。

- 見積番号「EST-20261113-01」
- 発行元の住所「〒100-0001 東京都千代田区1-1-1」
- 電話「03-1234-5678」、FAX「03-1234-5679」

どれも、いかにも実在しそうな形式の架空の情報です。さらに回答には「このまま取引先への送付資料としてご利用いただけます」と書かれていました。そのまま送れば、実在しない連絡先が載った見積書が取引先に届くところでした。

計算は正確でも、書類の形を整えるために無い情報を足す。この癖は、過去の実測（提案書でメモにない金額が足された回）でも出ています。

## 受け取り側のチェック

見積書を受け取ったら、金額の検算に加えて、次の点を見る必要があります。

- 見積番号や発行元の連絡先など、メモにない項目が足されていないか
- 足されていたら、実在する正しい情報に直したか、それとも消したか
- 「そのまま送れます」という言葉をうのみにしていないか
